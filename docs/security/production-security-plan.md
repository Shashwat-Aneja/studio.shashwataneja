Regional fixed windows are not a global exact quota.

Before rollout, confirm the project/environment and existing rule ordering, quotas and plan capability. Translate the draft into the current Vercel Firewall schema with all three predicates ANDed: environment production, method POST, exact path /api/booking-request. Never use a global all-path rule.
